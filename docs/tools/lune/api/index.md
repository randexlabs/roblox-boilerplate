# Lune API

Local API reference for the Lune modules that matter in this repo.

## Modules

- `fs.md`: filesystem access
- `process.md`: args, process spawning, execution
- `roblox.md`: mock Roblox instances and methods in tests
- `stdio.md`: prompts, stdin/stdout helpers
- `task.md`: scheduler and concurrency primitives
- `serde.md`: encode/decode, compression, hashing
- `net.md`: HTTP, servers, sockets, TCP
- `regex.md`: regex construction and matching
