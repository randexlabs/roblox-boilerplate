# Documentation index

This folder contains curated, modular docs intended for fast lookup and selective loading.

## Topics

- `architecture/index.md`: project architecture guidance; consult when changing domain boundaries, ownership, or abstraction level
- `luau/index.md`: Luau language notes (syntax, types, standard library, linter, embedding, performance)
- `principles/index.md`: engineering principles (DRY, KISS, SRP)
- `roblox-api/index.md`: Roblox engine API usage notes; consult when a task depends on engine-specific querying, selection, or service behavior
- `tools/index.md`: docs for external tools used in this repo
- `roblox-packages/index.md`: docs for third-party Roblox packages vendored in this repo
