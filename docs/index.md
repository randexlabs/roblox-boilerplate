# Documentation index

This folder contains curated, modular docs intended for fast lookup and selective loading.

## Topics

- `luau/index.md`: Luau language notes (syntax, types, standard library, linter, embedding, performance)
- `roblox-api/index.md`: Roblox engine usage notes; consult when a task depends on engine-specific querying, selection, replication behavior, or service behavior
- `tools/index.md`: docs for external tools used in this repo
- `roblox-packages/index.md`: docs for third-party Roblox packages vendored in this repo
